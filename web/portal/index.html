Forest Digital Twin

Field measurements, sensors, LiDAR products and growth simulations for the lab's forest sites, in one PostgreSQL/PostGIS database. Everything below reads and writes that same database; pick the door that fits what you want to do.

Explore

No account needed

  • ECOSENSE dashboard — trees, sensors, time series
  • Mathisle dashboard
  • Browse any table and download it as CSV
  • Tree look survey — rate whether trees look right for their species; by invitation, open it with the link you were sent

Contribute

Account with the contributor role

  • Add or correct data — forms, or paste a CSV
  • Run a model — SILVA projections, syncs, batches

Manage

Team leads (curator) and admins

  • Create accounts for your team, grant or revoke contributor, reset passwords
  • Correct and delete field data
  • Full SQL console (Supabase Studio): lab administrators only, through an SSH tunnel

Build

Developers

  • Developer guide — auth, read and write recipes in curl, Python and R, running models
  • Docs — how the data is organised, reference documentation, source repositories
  • Every table on this site is an endpoint under /db/rest/v1/

Getting access

Reading needs no account. To add data or run models, ask the curator of your team for an account; they can create one on the spot and give you a one-time password, which you change on the account page after your first sign-in.

RoleCan
read-onlyread everything public, see your own job history
contributoradd field data, edit sites and metadata (species, plots, sensors, campaigns, …), request model runs
curatoralso correct and delete field data, see every job, create accounts and grant contributor
